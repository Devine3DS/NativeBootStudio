# What may be distributed?

Review date: **10 October 2026**. This records the permissions verified for this package, not a guarantee covering every jurisdiction or acquisition method.

| Component | Public packaging decision |
| --- | --- |
| Native Boot Studio's own source | Included under MIT, with the license notice. |
| Frozen Python/Tcl/Tk/Pillow/PyInstaller/packaging runtime | Included with the upstream notices in `licenses/runtime/`. |
| Xenia | Its BSD-3-Clause license permits source/binary redistribution subject to its notice requirements. All bundled dependency terms would also need to be checked. This minimal release leaves it user-supplied. |
| XexTool 6.3 | No express redistribution grant was verified. Excluded; a download mirror is not proof of permission. |
| Original Microsoft `bootanim.xex` | No redistribution grant was verified. Excluded. Owning a console or obtaining a file is not itself a license to publish it. |
| Recolored or preview-adapted Microsoft XEX | Still contains Microsoft code/assets. Editing it does not make it MIT-licensed. Excluded. |
| Color preset JSON | The editor's preset format stores color/settings data, without boot animation code or assets. This is the intended way to share themes. |

For Xenia, see the [official BSD license at the tested source revision](https://github.com/xenia-project/xenia/blob/95a5c3ee2/LICENSE). Preserve the copyright, license conditions, and disclaimer when redistributing it; do not imply endorsement. The top-level license alone does not resolve every dependency in a compiled emulator build.

For Microsoft software, the [official copyright permissions page](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions) directs redistribution permissions to the applicable software license or terms. No permission covering publication of this boot animation was established here. Its boot-screen screenshot restrictions also matter for documentation; this repository uses only the editor's own preset-library UI.

XexTool is by xorloser. The [author's site](https://xorloser.com/) could not be used to verify an express redistribution license during this review. This is a missing permission verification, not a claim that the author has categorically forbidden all distribution. Obtain an explicit applicable grant before adding it to your release.

## Before publishing

Publish the clean source ZIP contents and the minimal Windows ZIP generated by the public packager. **Do not upload the older private 4.2 bundle**: it contains separately supplied files.

Exclude original and modified XEX files, tools, emulator binaries, NAND dumps, local settings, personal projects, exported examples, and your private fixture folders. The Git ignore rules help prevent mistakes; the ZIP packager also uses explicit allowlists. Inspect the final archive before uploading it.

Use your own program screenshots. Share themes as `.nbpalette.json` and let each user provide their own compatible original and tools.
