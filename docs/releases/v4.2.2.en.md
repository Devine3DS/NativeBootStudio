# Native Boot Studio 4.2.2

The **Files** tab now displays filenames only. Windows usernames and folder paths are hidden from the three file-selection fields. Missing files show **No file selected**. File loading, shader preview, export, and remembered local selections continue to use the original locations internally.

- File-selection fields are read-only; use the corresponding **Choose** button to change a file.
- File and preview error messages hide Windows user-profile folders.
- Filename labels remain unchanged when switching languages.
- The repository landing page now contains the full English tutorial, with a link to German, including HDD remap and direct NAND installation.

## Download and update

Download **NativeBootStudio-4.2.2-Windows-x64.zip**, extract it, and start `NativeBootStudio.exe`. Back up `UserPresets` before replacing an existing installation. To retain your selections, copy your existing local `settings.json` into the new application folder, or select your files again.

Provide your own unmodified modern 17559 `bootanim.xex` and XexTool 6.3. Xenia is optional for shader preview. These external files are not included. Local settings and projects can contain your own file locations; they are not bundled with the public download.

[English tutorial](https://github.com/Devine3DS/NativeBootStudio#native-boot-studio) · [Deutsche Anleitung](https://github.com/Devine3DS/NativeBootStudio/blob/main/README.de.md)

Use the attached `SHA256SUMS.txt` to verify the two ZIP downloads.
