# Native Boot Studio 4.2.1

A clean public release of the Windows editor for the modern native Xbox 360 boot animation.

- 40 coordinated color presets and a library for your own saved/imported/exported themes.
- English/German interface, undo/redo, projects, and supported layout/timing controls.
- Optional original-renderer shader preview through a separately selected Xenia installation.
- Complete `bootanim.xex` exports for an existing native HDD loader or NAND image-building workflow.
- First-run setup for user-supplied files and remembered paths.
- Organized source, tests, bilingual guides, license notices, and a Windows build workflow.
- Included HDD remap/direct NAND installation guides and a read-only CRC-32 helper; the remap itself is downloaded separately.

## Install

Download and extract **NativeBootStudio-4.2.1-Windows-x64.zip**, then start `NativeBootStudio.exe`. In Files, select your own unmodified modern **17559 `bootanim.xex`** and **XexTool 6.3**. For shader preview, separately obtain the [tested official Xenia build](https://github.com/xenia-project/release-builds-windows/releases/tag/v1.0.2844-master) and select `xenia.exe`.

Microsoft boot files, XexTool, and Xenia are **not included**. Instructions and runtime license notices are included. Check the attached `SHA256SUMS.txt` to verify the downloaded archives.

Back up `UserPresets` before replacing an existing installation. Share color preset JSON instead of XEX files. HDD export assumes an existing native loader; NAND export is an XEX, not a complete NAND image. Console behavior and changed animation/audio timing still require hardware verification. The classic animation and custom replacement text are not supported.
